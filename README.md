# SimpleCode

## 为什么开发
由于日常在超市或管理中需要频繁手动输入各种密码、链接和编码，繁琐且低效，为此开发了 SimpleCode 用于集中管理和快速调用。

## 设计灵感
操作方式灵感来源于 Google、Edge 与 Brave 浏览器的“主页快连接”，点击图标即可快速访问指定网址或内容。

## 核心功能

* **条码与二维码切换**：支持一维条码与二维码自由切换，解决部分特定或老旧扫码枪不支持 QR Code 的问题。
* **长按保存图片**：长按图标可将条码或二维码保存为本地图片。例如每次更改 Wi-Fi 密码时需要更新二维码，本应用可轻松解决。
* **标签与内容管理**：支持添加标签与对应内容（例如标签命名为 wifi，下方保存对应密码）。目前暂时不支持中文内容，也不支持 Emoji。
* **拖拽调整位置**：支持长按卡片并滑动，实时与目标卡片替换位置，自由调整标签排列顺序。
* **CSV 导出功能**：支持将数据导出为 CSV 文件传输到其他设备，避免在多台机器上重复手动录入标签和密码。
